# Третий мир (ThirdWorld) — разбор клиента «по полочкам»

Это старая онлайн-игра (MMO-стратегия) для кнопочных телефонов (**J2ME / MIDP-2.0**,
экран 176×208, сборка от **14.02.2009**, издатель Fenix-Soft). В репозитории лежит
только `.jar` клиента — сам сервер утерян. Наша цель: **вытащить из клиента сетевой
протокол**, понять «где логика», и научиться писать под него свой сервер.

Клиент подключается к серверу по TCP:

```
socket://mmog1.com:2500
```

(хост — поле `al.q = "mmog1.com"`, порт — `al.g = 2500`).

---

## 1. Почему классы называются `a`, `b`, `c`…

JAR прошли через **обфускатор** (ProGuard-подобный): имена классов, полей и методов
заменены на короткие `a`, `aa`, `ab`… Логика при этом сохранена — её видно в
байткоде через `javap -p -c`. Ниже — карта: что за что отвечает (имена восстановлены
по сигнатурам, строкам и вызовам).

## 2. Слои приложения

```
        ┌─────────────────────────────────────────────┐
        │  com.fenix.main.Main   — точка входа MIDlet    │
        └───────────────┬───────────────────────────────┘
                        │
      UI / экраны       ▼
   ap (Canvas, гл.цикл), n (менеджер экранов/сообщений),
   p, v, s, r, m … (игровые экраны и модели: замок, карта, юниты)
                        │
      Сессия / логика   ▼
   ar  — оркестратор соединения (потоки приёма/отправки, очередь)
   k   — менеджер логина и сессии (handshake, логин, разбор ответов)
   z   — хранилище состояния сессии + уникальный ID устройства (RMS)
                        │
      Протокол          ▼
   ae  — базовый пакет + кадр FLAP (маркер, канал, seq, длина)
   l   — пакет канала 1 (коннект/логин: логин, пароль, версия)
   f   — пакет канала 2 (данные: группа + подтип + payload)
   aj  — чтение/запись TLV (тип-длина-значение)
   t   — низкоуровневые хелперы (запись/чтение чисел + перекодировка CP1251)
   ak  — исключение протокола
                        │
      Транспорт         ▼
   g   — TCP-сокет: чтение в кольцевой буфер (поток-читатель), запись, reconnect
```

## 3. Карта классов (главное)

| Класс | Роль | Ключевое |
|-------|------|----------|
| `com.fenix.main.Main` | MIDlet, точка входа | манифест: `MIDlet-1: ThirdWorld,…,com.fenix.main.Main` |
| **`g`** | **TCP-транспорт** | `SocketConnection`, поток-читатель `run()`, кольцевой буфер 256 Б, `d={13,10}` (CRLF) |
| **`ae`** | **база пакета + кадр FLAP** | маркер `0x2A`, канал, seq, длина; `b()` — сериализация, `a(byte[])` — разбор |
| **`l`** | пакет **логина** (канал 1) | TLV: 1=логин, 2=пароль, 4=строка, 8=версия |
| **`f`** | пакет **данных** (канал 2) | `group` + `subtype` + payload |
| **`t`** | байт-хелперы + **CP1251** | big-endian числа; кириллица ↔ Windows-1251 |
| **`aj`** | **TLV** | `[тип:2][длина:2][значение]` |
| **`ak`** | исключение протокола | коды ошибок разбора |
| **`ar`** | **оркестратор соединения** | держит `g`+`k`, потоки приёма/отправки, очередь `Vector` |
| **`k`** | **логин / сессия** | handshake, отправка логина, разбор ответов сервера |
| **`z`** | состояние + **ID устройства** | `getUnicalID()` из RMS RecordStore |
| **`al`** | **конфиг/константы** | `q="mmog1.com"`, `g=2500`, цвета, шрифты |
| **`ap`** | главный Canvas / цикл | `k` — флаг «работаем», `o/p` — размеры экрана |
| **`i`** | загрузчик ресурсов | картинки юнитов/зданий, кэш в RMS |
| **`n`** | менеджер экранов/сообщений | принимает текстовые сообщения от сервера |
| `p,v,s,r,m,…` | игровые экраны и модели | замок, карта, юниты, ресурсы |

## 4. Ресурсы в JAR (не код, но полезно)

- `texts/strings.txt` — все игровые строки (здания, описания) в UTF-8.
- `build/*.png`, `units/**`, `ground/**`, `smallicon/**` — графика.
- `version.property` — версия мидлета `2.6.23`.

Дальше — самое важное: **`docs/02_PROTOCOL.md`** описывает формат кадра и пакетов,
а `docs/03_LOGIN_FLOW.md` — пошаговый сценарий «подключение → логин → игра».
